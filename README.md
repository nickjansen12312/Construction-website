# Bear Mechanical

## Missouri State University Construction Club

Bear Mechanical is a website project created for the Missouri State University Construction Club. The project is designed to represent a fictional mechanical and construction company while providing an opportunity to practice modern web development, responsive design, and interactive website features.

The website presents Bear Mechanical as a professional construction and mechanical contractor focused on engineering, construction, building systems, and future-ready solutions.

---

## About the Project

This project was created as part of a Missouri State University Construction Club project.

The goal of the website is to create a professional online presence for Bear Mechanical while allowing club members to gain hands-on experience with:

- HTML
- CSS
- JavaScript
- Responsive web design
- Website navigation
- Interactive elements
- Image and asset management
- Git and GitHub
- Basic web deployment

The design is inspired by modern construction, engineering, and architectural websites, with an emphasis on large imagery, typography, clean layouts, and subtle animations.

---

## Features

### Responsive Design

The website is designed to work across:

- Desktop computers
- Laptops
- Tablets
- Mobile phones

The navigation changes to a hamburger menu on smaller screens.

### Navigation

The website includes navigation for:

- About
- Safety
- Services
- Projects
- Work With Us
- Contact

The About section includes additional pages for:

- Our Story
- Meet the Team
- Culture & Values
- Awards

Services also includes:

- Mechanical
- Electrical
- Plumbing
- Automation

### Interactive Mobile Navigation

The mobile navigation includes expandable dropdown sections so users can access the same pages available through the desktop navigation.

### Animated Statistics

The homepage includes animated statistics that count upward when the statistics section enters the user's screen.

### Scroll-Based Effects

The website uses JavaScript and CSS to create interactive effects based on the user's scroll position.

The homepage also includes a large statement near the bottom of the page that can reveal itself as the user scrolls toward the end of the page.

### Project Showcase

The Projects page provides examples of Bear Mechanical's fictional work across different industries, including:

- Healthcare
- Commercial
- Industrial

### Careers

The Work With Us page includes:

- Company culture
- Career opportunities
- Open positions
- Employee benefits
- Application/contact information
